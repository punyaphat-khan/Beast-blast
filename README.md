# ✨ Beast Blast

Pick one of ten magical beasts, aim your wand, mind the wind, and blast the other beast!
Every beast has Attack + Defense + Speed adding up to 22, plus its own ★ Special spell
(burn, frost, shock, heal, shield, and more). Includes an original piano soundtrack.

## Play / install

Live page: **https://punyaphat-khan.github.io/beast-blast/**

- **iPad / iPhone:** open the page in **Safari** → tap **Share** → **Add to Home Screen**.
- **Android / Chrome:** tap the **📲 Install App** button on the main menu.

After it has opened once, it also works offline.

## Updating the game

Upload the new `index.html`, then change `beast-blast-v1` in `sw.js` to `beast-blast-v2`
(v3, v4… each time) so installed copies pick up the update.
